# EVE Quartermaster

I started EVE Quartermaster with tools for freighter jockeys like me. Then I kept adding EQM versions of tools I already used around New Eden. What started as a hauling toolkit grew into a self-hosted one-stop shop for different EVE playstyles, from moving freight and running industry to managing a corp and seeing where all that time and ISK went.

## What you can do

- **Hauling and navigation:** Plan stargate and jump-drive routes, including cyno stops and fuel estimates.
- **Assets and industry:** Find character and corporation assets and blueprints, and scout planets for PI.
- **Corporation management:** Manage member roles and permissions, review standings, and track activity in the audit log.
- **Analytics and intel:** Review mining, wallet, and combat activity. Export filtered Mining Ledger reports as CSV or JSON.

EQM connects characters through EVE SSO and uses an imported Static Data Export for local reference data. The Android app connects to an EQM instance you configure.
