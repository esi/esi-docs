# EVE Apex

<figure markdown="span" style="width: 250px; margin: auto;">
  ![EVE Apex](eve-apex-portrait.jpg)
</figure>

EVE Apex is a web application for EVE Online intelligence and analytics. It combines killmail-based character, corporation, alliance, and system intel with wormhole and Pochven tools, a D-Scan parser, corp recruitment, and a Discord server directory.

Login uses EVE SSO for authentication only (no extra ESI scopes).

## Features

- **Character, corporation, alliance, and system intel** — kill/loss analysis from zKillboard and ESI, including ship fits, weapon systems, and timezone activity.
- **Wormhole intel** — live J-space combat data, hottest systems, timezone patterns, and an entrance marketplace.
- **Pochven map** — interactive map of Triglavian systems with kill tracking and hunt intel.
- **D-Scan parser** — paste overview text for a parsed ship and DPS table.
- **Corp recruitment** — browse corporations by timezone, activity, and space.
- **Discord directory** — discover EVE Online Discord servers with live member counts.
