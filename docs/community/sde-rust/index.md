# SDE for Rust

`sde` is a Rust library that builds a SQLite database from EVE Online's Static Data Export (SDE) and reads it back, providing an abstraction layer over the data that makes searching it fast.

The library is under active development.

## Usage

Add the crate to your project:

```sh
cargo add sde
```

See the [documentation on docs.rs](https://docs.rs/sde) for the available API.
